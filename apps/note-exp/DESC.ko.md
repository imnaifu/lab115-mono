────────────────────
주요 기능
────────────────────
• 샤오홍슈(RedNote) 게시물의 모든 이미지와 동영상을 한 번에 다운로드, 하나의 폴더에 저장

• 동영상은 워터마크 없는 원본을 우선 다운로드하고, 불가능할 때는 일반 스트림으로 자동 전환

• 라이브 포토는 움직이는 영상까지 함께 저장하고, 게시물 본문(작성자, 게시일, IP 위치, 반응 수, 주제)은 note.txt로 저장

• 샤오홍슈 노트 목록을 클릭 한 번으로 CSV로 내보내기 — 홈 피드, 검색 결과, 사용자 프로필, 저장 탭 지원

• 샤오홍슈 게시물 페이지, 홈 피드, 검색 페이지, 프로필과 저장 탭에서 바로 사용 — xiaohongshu.com과 rednote.com 모두 지원

• 로그인 불필요, 계정 정보 수집 없음

• 모든 데이터는 브라우저 안에서만 처리

• 한국어를 포함한 6개 언어 인터페이스 지원(简体中文、繁體中文、English、한국어、日本語、Tiếng Việt), 브라우저 언어에 맞춰 자동 전환

────────────────────
사용 방법
────────────────────
게시물의 이미지, 동영상, 본문 다운로드

1. 샤오홍슈 게시물을 엽니다

2. 확장 프로그램 아이콘을 클릭하고 "게시물 다운로드" 탭을 엽니다

3. 원하는 이미지, 동영상, 본문을 선택하고 하나의 폴더로 다운로드합니다

노트 목록 내보내기

1. 샤오홍슈 홈 피드, 검색 결과, 사용자 프로필 또는 저장 탭을 열고 노트가 로드될 때까지 기다립니다

2. 확장 프로그램 아이콘을 클릭하고 "노트 목록 내보내기" 탭을 엽니다

3. 계속 스크롤하면 노트가 더 수집됩니다. "CSV 내보내기"로 저장하고, "지우기"로 다시 시작합니다

────────────────────
개인정보 및 보안
────────────────────
• 개인 데이터를 수집, 저장, 전송하지 않습니다
