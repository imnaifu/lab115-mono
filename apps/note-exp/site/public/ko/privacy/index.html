Chrome에 추가

개인정보처리방침

Chrome 확장 프로그램 「RedNote Exporter」 · 최종 업데이트: 2026년 11월 13일

이 페이지는 번역본입니다. 내용이 다를 경우 영어 원문이 우선합니다.

요약: 수집하거나 다운로드한 노트, 이미지, 동영상은 브라우저 밖으로 나가지 않습니다. 무엇을 먼저 개선할지 알기 위해, 확장 프로그램은 익명 사용 횟수(어떤 기능을 얼마나 자주 쓰는지)를 저희가 직접 운영하는 통계 서버로 보냅니다. 여기에는 노트 내용, 링크, 계정 정보가 포함되지 않으며, 확장 프로그램의 ⋯ 메뉴에서 끌 수 있습니다.

확장 프로그램이 읽는 정보

확장 프로그램은 xiaohongshu.com과 rednote.com 페이지에서만 실행되며, 해당 페이지가 스스로 불러온 노트 데이터만 읽습니다.

  • 노트 목록 — 홈 피드, 검색 결과, 프로필 페이지와 저장 탭이 불러온 노트: 제목, 작성자, 게시 시간, 반응 수(좋아요, 저장, 댓글, 공유), 커버와 이미지 링크.
  • 단일 게시물 — 다운로드하거나 텍스트 파일로 저장하기 위해, 현재 열려 있는 게시물의 이미지·라이브 포토·동영상 링크와 본문, 주제, IP 위치, 반응 수.

이 모든 정보는 페이지에 이미 공개적으로 보이는 콘텐츠입니다. 확장 프로그램은 샤오홍슈 계정 정보, 메시지, 쿠키, 비밀번호를 읽지 않으며, 샤오홍슈에 별도의 요청을 보내지 않습니다. 사용자가 탐색하는 동안 페이지가 이미 받은 데이터만 읽습니다.

익명 사용 통계

사용자들이 실제로 어떤 기능을 쓰는지 알기 위해, 확장 프로그램은 저희가 직접 운영하는 통계 서버(Umami, stats.lab115.com)로 몇 가지 익명 이벤트를 보냅니다.

  • 보내는 시점: 확장 프로그램을 설치하거나 업데이트할 때, 그리고 팝업을 열거나, 탭을 바꾸거나, 노트 목록을 내보내거나, 게시물을 다운로드하거나, 목록을 비우거나, 원본 게시물을 열거나, 인터페이스 언어를 바꿀 때.
  • 포함되는 정보: 현재 페이지의 종류(홈 피드, 검색, 프로필, 게시물, 기타)와 xiaohongshu.com인지 rednote.com인지; 내보낸 노트 수, 다운로드한 이미지·동영상·라이브 포토·텍스트 파일 수와 다운로드를 시작하지 못한 수 같은 개수; 동영상이 워터마크 없는 원본이었는지; 인터페이스 언어와 브라우저 언어; 확장 프로그램 버전; 그리고 설치할 때 무작위로 만들어지는 설치 ID(사용자 수와 재방문 여부를 세는 데 사용).
  • 절대 포함하지 않는 정보: 노트 ID, 링크, 제목, 본문, 작성자 이름, 검색어, 파일 이름, 샤오홍슈 계정, 쿠키, 그리고 다른 웹사이트 방문에 관한 어떤 정보도.
  • 네트워크 정보: 모든 웹 요청과 마찬가지로 통계 서버는 IP 주소와 브라우저 정보(User-Agent)를 받습니다. 서버는 이를 대략적인 국가와 브라우저·운영체제 종류를 파악하는 데만 쓰고, IP 주소는 저장하지 않습니다.
  • 끄는 방법: 확장 프로그램 팝업에서 ⋯를 누르고 「익명 사용 통계」를 끄세요. 그 이후로는 아무것도 보내지 않습니다.

통계는 저희 서버에만 보관되며, 확장 프로그램을 개선하는 데만 쓰이고, 판매하거나 공유하지 않습니다.

제거할 때

확장 프로그램을 제거하면 Chrome이 이 웹사이트의 짧은 페이지를 열어 제거 이유를 묻습니다. 페이지 주소에는 확장 프로그램 버전이, 사용 통계가 켜져 있었다면 설치 ID도 함께 담겨 있어 답변을 그 설치에서 쓴 기능과 연결할 수 있습니다. 답변은 선택 사항입니다.

이 웹사이트

rednote.lab115.com은 같은 자체 운영 Umami로 방문을 집계합니다: 본 페이지, 유입 사이트, 대략적인 국가, 브라우저와 기기 종류, 「Chrome에 추가」 버튼 클릭. 쿠키를 쓰지 않으며 제3자 분석 도구도 쓰지 않습니다.

데이터 보관 위치

  • 수집한 노트는 현재 탭의 메모리에만 있습니다. 탭을 닫거나 새로고침하거나 「지우기」를 누르면 삭제됩니다.
  • 「CSV 내보내기」나 「다운로드」를 누르면 브라우저가 파일을 다운로드 폴더에 바로 저장합니다. 이미지와 동영상은 브라우저가 샤오홍슈 미디어 서버에서 직접 받으며, 저희를 거치지 않습니다.
  • 확장 프로그램이 로컬에 저장하는 것은 세 가지뿐입니다: 언어 메뉴에서 고른 인터페이스 언어, 사용 통계를 켰는지 여부, 무작위 설치 ID.

하지 않는 일

  • 수집하거나 다운로드한 노트, 이미지, 동영상, 본문을 저희 서버나 제3자에게 보내지 않습니다.
  • 제3자 분석, 광고, 추적 도구를 사용하지 않습니다.
  • 어떤 데이터도 판매, 대여, 공유하지 않습니다.
  • 백그라운드에서 아무것도 수집하지 않습니다. 사용자가 샤오홍슈 페이지를 보는 동안에만 그 페이지를 처리합니다.

권한

  • downloads — 선택한 이미지와 동영상을 다운로드 폴더에 저장하며, 시간과 게시물 제목으로 이름 붙인 하위 폴더 하나에 모읍니다.
  • storage — 사용 통계 설정과 설치 ID를 기억합니다.
  • xiaohongshu.com 및 rednote.com 접근(edith, so 하위 도메인 포함) — 해당 페이지에서 실행되어 페이지가 불러온 노트 데이터를 읽습니다. 다른 사이트에서는 실행되지 않습니다.

다운로드한 콘텐츠

이 확장 프로그램으로 다운로드하거나 내보낸 콘텐츠의 권리는 원작자에게 있습니다. 개인 및 연구 목적으로만 사용하고 샤오홍슈 이용약관과 관련 법률을 지켜 주세요. RedNote Exporter는 샤오홍슈(RedNote)와 제휴하거나 승인·허가를 받지 않았습니다.

방침 변경

확장 프로그램의 데이터 처리 방식이 바뀌면 이 페이지와 위의 날짜를 업데이트합니다.
