Privacy Policy

For the Chrome extension “RedNote Exporter” · Last updated: November 13, 2026

In short: the notes, images and videos you capture or download never leave your browser. The extension sends anonymous usage counts (which features are used, and how often) to our own statistics server so we know what to improve. They never include note content, links or your account, and you can turn them off in the extension’s ⋯ menu.

What the extension reads

The extension runs only on xiaohongshu.com and rednote.com pages, and only reads the note data those pages load themselves:

  • Note lists — notes loaded by the home feed, search results, profile pages and Collections tabs: title, author, publish time, engagement counts (likes, collects, comments, shares), cover and image links.
  • A single post — the image, Live Photo and video links, text, topics, IP location and engagement counts of the post you have open, so they can be downloaded or saved as a text file.

All of this is content already publicly visible on the page. The extension does not read your RedNote account details, messages, cookies or passwords, and it never sends requests of its own to RedNote — it only reads data the page has already received while you browse.

Anonymous usage statistics

To learn which features people actually use, the extension reports a few anonymous events to our self-hosted statistics server (Umami, at stats.lab115.com):

  • When: the extension is installed or updated, and when you open its popup, switch tabs, export a note list, download a post, clear the list, open the original post or change the interface language.
  • What an event contains: the kind of page you are on (home feed, search, profile, a post or other) and whether it is xiaohongshu.com or rednote.com; counts such as how many notes were exported, or how many images, videos, Live Photos and text files were downloaded and how many failed to start; whether a video was the watermark-free original; the interface and browser language; the extension version; and a random install ID created when the extension is installed, used to count users and see whether they come back.
  • What it never contains: note IDs, links, titles or text, author names, search words, file names, your RedNote account, cookies, or anything about other websites you visit.
  • Network details: like any web request, a report reaches the server with your IP address and browser user agent. The server uses them to work out the approximate country and the browser and operating system, and does not store the IP address.
  • Turning it off: click ⋯ in the extension’s popup and switch off “Anonymous usage stats”. From then on nothing is sent.

The statistics stay on our own server, are used only to improve the extension, and are never sold or shared.

When you uninstall

After the extension is removed, Chrome opens a short page on this website asking why. Its address carries the extension version and, if usage statistics were on, the install ID, so an answer can be matched to the features that install used. Answering is optional.

This website

rednote.lab115.com counts visits with the same self-hosted Umami: pages viewed, the referring site, approximate country, browser and device type, and clicks on the “Add to Chrome” buttons. It sets no cookies and uses no third-party analytics.

Where data is kept

  • Captured notes live only in the memory of the current tab. Closing or reloading the tab, or clicking Clear, discards them.
  • When you click Export CSV or Download, your browser saves the files straight to your Downloads folder. Images and video are fetched by your browser directly from RedNote's media servers, never through us.
  • The extension keeps three small things locally: the interface language you picked from its language menu, whether usage statistics are on, and the random install ID.

What we don't do

  • We never send the notes, images, videos or text you capture or download to our servers or anyone else.
  • We do not use third-party analytics, advertising or tracking tools.
  • We do not sell, rent or share any data.
  • We do not collect anything in the background. The extension only handles a RedNote page while you are browsing it.

Permissions

  • downloads — saves the images and video you select to your Downloads folder, grouped into one sub-folder named after the time and post title.
  • storage — remembers the usage-statistics setting and the install ID.
  • Access to xiaohongshu.com and rednote.com (including the edith and so subdomains) — lets the extension run on those pages and read the note data they load. It does not run on any other site.

Content you download

Content downloaded or exported with this extension remains the property of its original authors. Please use it for personal and research purposes only, and follow RedNote's terms of service and applicable law. RedNote Exporter is not affiliated with, endorsed by or authorized by RedNote (Xiaohongshu).

Changes to this policy

If the way the extension handles data ever changes, we will update this page and the date above.
