Chrome に追加

プライバシーポリシー

Chrome 拡張機能「RedNote Exporter」 · 最終更新：2026 年 11 月 13 日

このページは翻訳版です。内容に相違がある場合は英語版が優先します。

要点：収集・ダウンロードしたノート、画像、動画がブラウザの外に出ることはありません。何を優先して改善するかを知るため、拡張機能は匿名の利用回数（どの機能がどれくらい使われたか）を私たちが自前で運用する統計サーバーに送ります。ノートの内容・リンク・アカウント情報は含まれず、拡張機能の ⋯ メニューからオフにできます。

拡張機能が読み取るもの

拡張機能は xiaohongshu.com と rednote.com のページでのみ動作し、それらのページ自身が読み込んだノートデータだけを読み取ります。

  • ノート一覧 — ホームフィード、検索結果、プロフィールページ、コレクションが読み込んだノート：タイトル、投稿者、投稿日時、反応数（いいね、保存、コメント、シェア）、カバーと画像のリンク。
  • 単一の投稿 — ダウンロードやテキストファイル保存のため、開いている投稿の画像・ライブフォト・動画のリンクと、本文、トピック、IP 所在地、反応数。

これらはすべて、ページ上ですでに公開されている内容です。拡張機能は小紅書のアカウント情報、メッセージ、Cookie、パスワードを読み取らず、小紅書へ独自にリクエストを送ることもありません。閲覧中にページがすでに受け取ったデータを読むだけです。

匿名の利用統計

実際にどの機能が使われているかを知るため、拡張機能は私たちが自前で運用する統計サーバー（Umami、stats.lab115.com）にいくつかの匿名イベントを送ります。

  • 送るタイミング：拡張機能のインストール時と更新時、そしてポップアップを開いたとき、タブを切り替えたとき、ノート一覧を出力したとき、投稿をダウンロードしたとき、一覧をクリアしたとき、元の投稿を開いたとき、表示言語を変えたとき。
  • 含まれるもの：今いるページの種類（ホームフィード、検索、プロフィール、投稿、その他）と、xiaohongshu.com か rednote.com か。出力したノートの件数、ダウンロードした画像・動画・Live Photos・テキストファイルの数と開始できなかった数などの件数。動画が透かしなしの元ファイルだったか。表示言語とブラウザの言語。拡張機能のバージョン。インストール時にランダムに作られるインストール ID（利用者数と再利用の有無を数えるため）。
  • 決して含まないもの：ノートの ID、リンク、タイトルや本文、投稿者名、検索語、ファイル名、小紅書のアカウント、Cookie、ほかのウェブサイトの閲覧に関する情報。
  • 通信に伴う情報：あらゆるウェブリクエストと同じく、統計サーバーには IP アドレスとブラウザの識別情報（User-Agent）が届きます。サーバーはこれらをおおよその国、ブラウザと OS の種類の判定にだけ使い、IP アドレスは保存しません。
  • オフにする方法：拡張機能のポップアップで ⋯ を押し、「匿名の利用統計」をオフにしてください。以後は何も送信されません。

統計は私たちのサーバーにだけ保存され、拡張機能の改善にのみ使い、販売や共有はしません。

アンインストールしたとき

拡張機能を削除すると、Chrome がこのサイトの短いページを開き、削除の理由をお聞きします。ページのアドレスには拡張機能のバージョンと、利用統計がオンだった場合はインストール ID が含まれ、回答をそのインストールで使われた機能と結び付けられます。回答は任意です。

このウェブサイト

rednote.lab115.com は同じ自前の Umami でアクセスを集計しています：閲覧されたページ、参照元サイト、おおよその国、ブラウザと端末の種類、「Chrome に追加」ボタンのクリック。Cookie は使わず、第三者の分析ツールも使いません。

データの保存場所

  • 収集したノートは現在のタブのメモリ内にのみ存在します。タブを閉じる、再読み込みする、または「クリア」を押すと破棄されます。
  • 「CSV を出力」や「ダウンロード」を押すと、ブラウザがファイルを直接ダウンロードフォルダに保存します。画像と動画はブラウザが小紅書のメディアサーバーから直接取得し、私たちを経由することはありません。
  • 拡張機能がローカルに保存するのは 3 つだけです：言語メニューで選んだ表示言語、利用統計のオン・オフ、ランダムなインストール ID。

行わないこと

  • 収集・ダウンロードしたノート、画像、動画、本文を私たちのサーバーや第三者に送信しません。
  • 第三者の分析、広告、トラッキングのツールを使用しません。
  • データを販売、貸与、共有しません。
  • バックグラウンドで何かを収集することはありません。拡張機能が小紅書のページを扱うのは、そのページを閲覧している間だけです。

権限

  • downloads — 選択した画像と動画をダウンロードフォルダに保存し、時刻と投稿タイトルの名前を付けたサブフォルダにまとめます。
  • storage — 利用統計の設定とインストール ID を記憶します。
  • xiaohongshu.com と rednote.com へのアクセス（edith と so のサブドメインを含む）— それらのページで動作し、ページが読み込んだノートデータを読み取ります。ほかのサイトでは動作しません。

ダウンロードしたコンテンツ

この拡張機能でダウンロードまたは出力したコンテンツの権利は、元の作者に帰属します。個人利用および研究目的でのみ使用し、小紅書の利用規約と関連法令を守ってください。RedNote Exporter は小紅書（RED / RedNote）と提携しておらず、承認や許可も受けていません。

ポリシーの変更

拡張機能のデータの扱いが変わる場合は、このページと上記の日付を更新します。
