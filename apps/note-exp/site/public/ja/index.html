よくある質問

FAQ
無料ですか？

はい。有料機能はなく、アカウント登録も不要です。

動画はいつも透かしなしですか？

透かしなしの元ファイルが取得できる場合は必ずそれを優先します。取得できない一部の投稿では通常の動画ストリームに切り替わり、その場合は透かしが入ることがあります。

CSV に空の列があるのはなぜ？

保存・コメント・シェア数と投稿日時がすべてそろうのは検索結果だけで、ホームフィードとプロフィールはいいね数のみです。小紅書から返されなかった値は 0 で埋めずに空欄にしているので、空欄は「データなし」を意味し、0 件ではありません。

収集したノートはどこに保存されますか？

現在のタブの中だけです。タブを閉じるか「クリア」を押すと消えます。出力した CSV やダウンロードしたファイルはパソコンのダウンロードフォルダに保存され、どこにもアップロードされません。

対応サイトとブラウザは？

xiaohongshu.com と rednote.com の両方に対応しています。Chrome 向けですが、Edge や Brave などの Chromium 系ブラウザでも、たいてい Chrome ウェブストアからインストールできます。
