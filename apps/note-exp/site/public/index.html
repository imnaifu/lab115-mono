FAQ

Is it free?

Yes. There are no paid features and no account to create.

Are the videos always watermark-free?

The extension downloads the watermark-free original whenever it is available. For the occasional post where it isn't, it falls back to the regular video stream, which may carry a watermark.

Why are some CSV columns empty?

Only search results return the full collect, comment and share counts and the publish time; the home feed and profile pages return the like count only. Columns RedNote didn't return are left empty rather than filled with 0, so a blank cell means “not provided”, not a count of zero.

Where are the captured notes kept?

Only in the current tab. Closing the tab or clicking Clear discards them. Exported CSVs and downloaded files go to your own Downloads folder and are never uploaded anywhere.

Which sites and browsers are supported?

Both xiaohongshu.com and rednote.com. It is built for Chrome; Chromium-based browsers such as Edge and Brave can usually install it from the Chrome Web Store too.
