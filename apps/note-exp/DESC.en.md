────────────────────
Key Features
────────────────────
• Export RedNote note lists to CSV with one click — home feed, search results, and user profiles

• Download all images and the video from a single post into one folder

• Works directly on RedNote's home feed, search pages, profile pages, and post pages

• No login required, no account data collected

• All data is processed locally in your browser

────────────────────
How to Use
────────────────────
Export a note list

1. Open RedNote's home feed, a search results page, or a user profile and let notes load

2. Click the extension icon and open the "Export Note List" tab

3. Keep scrolling to capture more notes, click "Export CSV" to save, or "Clear" to start over

Download a single post

1. Open any RedNote post

2. Click the extension icon and open the "Download Post Assets" tab

3. Select the images and video you want, then download them into one folder

────────────────────
Privacy & Security
────────────────────
• This extension does NOT collect, store, or transmit any personal data

• No external servers are used

• All exported and downloaded content comes from publicly available RedNote pages
