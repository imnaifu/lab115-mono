# 话题配图

`<category id>.webp` — 一个话题一张，id 取自 `config.json` 的 `categories[].id`：

    tech.webp  business.webp  investing.webp  economy.webp
    science.webp  design.webp  living.webp  culture.webp

**放进来就生效，拿走就退回渐变。** 没有配置项要改，也没有构建步骤 —— 见
`src/components/TopicImage.tsx`：分类自己的强调色渐变**永远**画在底下，照片盖在上
面，所以文件缺失、404 或超时都会落到一张设计过的底图，而不是空盒子或浏览器的破图
标记。

## 尺寸

两处在用，同一张图：

    话题总览的卡片   ~400×225 显示（16:9）
    话题页顶部的带   ~750×280 显示

所以 **1600×900 够用**，再大只是让读者多下载。

**WebP，质量 72**（`sharp().webp({ quality: 72, effort: 6 })`）。同一批图 JPEG q80 是
1212KB、WebP q72 是 646KB —— 省一半，肉眼看不出差别。单张落在 40–95KB，八张加首页
那张一共 646KB，这些会一起进仓库、一起进镜像，所以体积是真成本。

原图先缩到 1600×900 再编码：站上最宽的容器是 750px 的正文栏，1600 已经是 2 倍屏的
量，更大的源图只是让每个读者多下载。

## 授权

这些图会公开挂在站上。只放**有权发布**的图：自己拍的、买了授权的、或者明确标了可
商用且不要求署名的。需要署名的图不要放这里 —— 这个组件没有署名位，而站上唯一有署
名位的图是维基每日照片（见 `DailyPhoto` 和 `components/Photo`，那里的署名是许可
义务）。
