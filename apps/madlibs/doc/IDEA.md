# Mad Libs AI 搞笑故事短视频

记录日期：2026-10-21

状态：想法阶段，需求、售价和产品形态尚未验证。

## 产品概念

用户填写名字、地点、食物、形容词等，在不知道故事内容的情况下，拼出搞笑故事，再生成可分享的图片或 15–30 秒短视频。

用户流程：选择主题 → 回答 5–8 个填词问题 → 揭晓故事 → 重玩或生成视频 → 下载分享。

核心乐趣是信息差：模板保证句子通顺，意料之外的词语组合制造笑点。

## 故事机制

模板示例：

```
有一天，{name} 来到 {place}，发现一只 {adjective} 的猫正在吃 {food}。
{name} 大喊：“这是我的午饭！”
```

输入：小明、月球、毛茸茸、火锅。

结果：有一天，小明来到月球，发现一只毛茸茸的猫正在吃火锅。小明大喊：“这是我的午饭！”

| 方案 | 做法 | 取舍 |
| --- | --- | --- |
| 固定模板 | 程序替换占位符 | 可控、成本低；笑点依赖模板 |
| AI 预生成模板 | 先固定隐藏模板，再收集答案 | 增加变化，保留经典揭晓机制 |
| AI 根据答案写故事 | 输入后即时创作 | 更灵活，但可能把离谱组合解释得过于合理 |

建议先用固定模板验证，再考虑 AI 扩充主题。此项为建议，尚未最终决定。

## 产品形态与技术

候选形态：独立网页，或 ChatGPT 插件。建议共用业务后台；先做哪一种待定。

MCP Server 将业务函数注册为 tools。客户端通过 tools/list 获取名称、描述和 inputSchema，通过 tools/call 调用。后端执行函数，返回 content 和可选 structuredContent；ChatGPT 负责理解输入、提问和组织回答。

接口草案（项目自定义，非官方预设）：

| 工具 | 功能 |
| --- | --- |
| start_game(theme) | 保存隐藏模板，返回 game_id 和填词问题 |
| submit_answers(game_id, answers) | 校验并保存答案 |
| reveal_story(game_id) | 替换变量并返回故事 |
| create_story_video(story_id, style) | 发起异步任务，返回 job_id |
| get_video_status(job_id) | 查询进度，完成后返回视频链接 |

技术候选：TypeScript + MCP SDK；数据库保存状态；任务队列运行视频生成；对象存储保存素材；FFmpeg 或 Remotion 合成。

模板在揭晓前留在后端。游戏和任务绑定用户或会话。涉及私有数据、付费操作时，加入认证、权限校验、额度限制、幂等处理和操作日志。

## 视频方案

| 路线 | 实现 | 取舍 |
| --- | --- | --- |
| 图片动画 | 场景图片 + 缩放平移 + 字幕 + 配音 | 成本可控，适合首版 |
| AI 动态视频 | 每个镜头生成短片，再剪辑 | 成本高，角色一致性与重试需要控制 |
| 混合方案 | 图片讲故事，最后反转生成 5 秒动态片段 | 兼顾效果和成本 |

建议先尝试图片动画或混合方案。姓名、中文字幕和填词高亮后期叠加；先固定角色参考图再逐镜头生成。

流程：故事拆分镜 → 场景图 → 按需生成动态片段 → 配音 → 按配音时长安排镜头 → 叠加字幕音效 → 导出竖屏 MP4。

示例：输入词弹出（4 秒）→ 小明到月球（6 秒）→ 猫吃火锅（7 秒）→ 小明喊“这是我的午饭”（5 秒）。

## 免费试用选项补充

核对日期：2026-10-21。免费网页试用不等于免费 API，不能据此设计长期零成本服务。

| 工具 | 当前可确认的信息 | 注意事项 |
| --- | --- | --- |
| Adobe Firefly | 有有限每日免费生成，可用于指定模型的图片、音频和视频 | 具体次数和模型以账户显示为准 |
| Runway | 一次性 125 积分，不到期，用完不刷新 | 免费模型范围可能调整，登录确认；适合测试 |
| Pika | 当前价格页写 Free 每月 0 积分，需购买积分包 | 旧 FAQ 的每月 150 积分不应继续作为依据 |

如果要持续低成本生成，优先使用自有或有授权的图片，配字幕、缩放和转场，通过 FFmpeg 合成；这是图片动画，不是逐帧 AI 动态视频。仍有计算、存储及流量成本。

## 商业模式假设

- 文字故事免费，降低试玩门槛。
- 视频按次收费或出售点数包；基础图片动画与 AI 动态视频分档。
- 后续扩展主题包、节日玩法和多人填词。
- 流量广告待访问量与用户体验验证后再评估。

候选用户场景：朋友整活、聚会、情侣或家庭娱乐、社交媒体分享。尚未验证目标市场与付费意愿。
