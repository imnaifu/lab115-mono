# 硅谷幸存者 · 游戏设计与机制

> 这是游戏机制的**权威文档**：玩法规则、数值、节奏、界面上该出现什么。改玩法、数值或界面时同一次改动里更新这里，并在末尾「变更记录」加一行；数值以代码为准时，在这里写清楚出处（文件和常量名）。
> 更偏实现的说明在 `README.md`；面向外部讨论的完整背景在 `../docs/`（不入库）。
>
> 当前版本：`2026-10-28.8`（`scripts/telemetry.gd` 的 `VERSION`）。

## 1. 概述

- **一句话**：躲开 Bug、会议和 Deadline，撑过 10 分钟就能敲钟上市。割草类 roguelike（自动攻击，玩家只管走位和升级时选卡），题材是恶搞硅谷职场。
- **平台**：网页（https://survivors.lab115.com），手机竖屏单手为主，电脑横屏。玩家主要从微信聊天里点链接进来。
- **单局**：10 分钟，撑到就赢。只有一个难度，没有局外成长（规划见第 7 节）。
- **操作**：手机按住屏幕任意处拖动（虚拟摇杆），可选陀螺仪；电脑 WASD / 方向键；升级时点卡或按数字键。

## 2. 一局里的机制

### 2.0 流程

1. 开始画面点「开始搬砖」。
2. 主角（程序员）出生在湾区地图中部（帕洛阿尔托 / 山景城），自带「回车键」。
3. 怪从屏幕外刷出来朝主角走；武器全自动攻击；打死的怪掉经验星星，走近才会被吸过来。
4. 经验满了升级：暂停，弹出 3 张卡（武器或被动）选一张。
5. 每分钟来一个 boss，必掉「融资钱袋」，捡到时开老虎机式的奖励。
6. 撑满 10:00 就赢；生命归零就输。结算页显示数据、死因和建议，可以生成战绩图、再来一局。

### 2.1 主角基础属性

| 属性 | 初始值 | 说明 |
|---|---|---|
| 生命 | 100 | 脚下血条里只写当前血量 |
| 移速 | 62 像素/秒 | 逻辑分辨率 640×360 |
| 拾取范围 | 40 像素 | 星星进入范围后飞过来 |
| 受击无敌 | 0.5 秒 | 碰到怪扣血后短暂无敌 |
| 护甲 | 0 | 每点护甲让每次受到的伤害 -1 |
| 伤害倍率 / 冷却倍率 | 1.0 / 1.0 | 被动会改 |

接触伤害：同一时刻碰到多个怪时，只取伤害最高的那个；之后无敌 0.5 秒。

### 2.2 武器（6 把，每把 5 级，最多带 6 把）

| 武器 | 攻击方式 | 1→5 级数值 |
|---|---|---|
| 回车键（开局自带） | 朝最近的敌人连发，射程 200 | 每轮发数 1/2/2/3/3，伤害 12/12/18/18/24，穿透 1/1/1/1/3，冷却 1.1 秒 |
| 复制粘贴 | 朝面向的方向并排连发文件 | 并排数 1/1/2/2/3，伤害 10/14/14/18/18，穿透 2/2/2/2/3，冷却 0.7/0.7/0.7/0.7/0.5 秒 |
| 无人机 | 飞出去追附近（150 内）的敌人撞，撞完弹开找下一个 | 架数 1/2/2/3/4，伤害 9/9/13/13/17，速度 150/150/175/175/200 |
| 云端部署 | 从云上劈屏幕里的随机敌人，带小范围溅射，必中 | 道数 1/2/2/3/4，伤害 16/16/22/22/28，溅射半径 12/12/12/16/18，冷却 2.6/2.6/2.4/2.4/2.0 秒 |
| 机械键盘 | 往上抛，落下砸穿一切（无限穿透） | 个数 1/2/2/3/3，伤害 24/24/34/34/44，第 5 级体积 ×1.4，冷却 2.2 秒 |
| Wi-Fi 信号 | 身边一圈持续伤害并推开敌人 | 半径 40/46/46/54/62，伤害 6/6/9/9/13，每 0.6/0.6/0.5/0.5/0.4 秒一跳 |

设计意图：无人机管中距离的散兵，Wi-Fi 管贴身的；云端部署必中所以数值压得低。所有伤害都乘主角的伤害倍率，冷却都乘冷却倍率。目前**没有武器进化**。

### 2.3 被动（14 种，一局最多带 6 种，大多 5 级）

| 被动 | 每级效果 |
|---|---|
| 冰美式 | 所有伤害 +10% |
| 降噪耳机 | 受到的伤害 -1（每次） |
| 撸铁 | 最大生命 +20，并回复 20 |
| 电动滑板 | 移速 ×1.08 |
| 双屏显示器 | 武器冷却 ×0.92 |
| 人脉名片 | 拾取范围 ×1.3 |
| 工位绿植 | 每秒回复 +0.3 生命 |

有自己玩法的 7 种（1→5 级）：

| 被动 | 效果 |
|---|---|
| 股票期权 | 拿到后每撑过 1 分钟，伤害永久 +2% × 等级（越早拿越赚） |
| 背锅侠 | 挨打时，身边 70 像素内的怪受到「这次掉的血 × 3/4/5/6/8」的伤害 |
| 降本增效 | 打死的怪有 5/8/11/14/18% 几率爆炸（半径 36，伤害 18/24/30/36/45），能连环炸 |
| 开源项目 | 打死怪有 2/3/4/5/6% 几率留下一个小炮台，自动打怪 8 秒（同时最多 4 个） |
| 站会 | 每 14/12/10/9/8 秒震开并定住身边 100 像素内的怪 1 秒，伤害 10–30 |
| 午休 | 站着不动 1 秒后，每秒回复 1.5/2.5/3.5/4.5/6 生命，头上冒 Zz |
| 猎头电话 | 升级时多 1 个选项（最多 2 级，也就是最多 5 选 1） |

### 2.4 升级规则

- **经验曲线**：前 4 次升级分别要 3 / 7 / 13 / 20 点经验；之后第 L 级要 `5 + (L-1)×6 + max(0, L-20)×4`。
- **出卡**：默认 3 张，猎头电话每级 +1。卡池按权重随机：没拿过的武器权重 2、已有武器的下一级权重 3（鼓励成型）、被动权重 2。被动带满 6 种后只出已有被动的升级。
- **新手保底**（`.5` 新加）：每局第 1 次升级至少出 2 张新武器卡，第 2 次至少 1 张。手上不到 3 把武器时，新武器卡上标「推荐」。原因是线上数据里新手常常前几次全选被动，只有 1 把武器，3、4 分钟就死。
- **卡面**：名字、图标、等级点、一句文案，加一行蓝字写具体数字（比如「伤害 18 → 24 · 穿透 1 → 3」，武器最多列两项，数字已经算上当前加成）。
- **全部满级之后**：只出「摸鱼一会儿」（回复 30 生命）。
- 弹出升级面板后有 0.3 秒不接受选择，防止误触。

### 2.5 掉落与「融资开奖」

| 掉落 | 来源 | 效果 |
|---|---|---|
| 经验星星（蓝 / 绿 / 金按数值分档） | 每个怪 | 走近才被吸过来；地上超过 400 个时新经验并进已有的星星 |
| 珍珠奶茶 | 普通怪 1.2% | 回复 30 生命 |
| 磁铁 | 普通怪 0.4% | 全图星星飞过来 |
| 融资钱袋 | 每个 boss 必掉（同时还掉奶茶和磁铁） | 融资开奖 |

**融资开奖**（`.5` 新加，参考 Vampire Survivors 的宝箱）：捡到钱袋时游戏暂停，老虎机在「天使轮 / A 轮 / IPO」之间转 1.6 秒后停下，分别白给 1 / 3 / 5 样升级，概率 75% / 20% / 5%。给的是**身上已有**的武器和被动随机升一级，全都满级了才出新东西。以前钱袋是「免费升级一次（自己选）」。

Boss（精英）：头顶有血条，屏幕上方的 boss 条显示名字和血条，必掉钱袋。所有招式出手前都会画出预警（红色通道、落点圈、蓄力圈），保证能躲。

| 7:30 | 需求变更 | 1700 | 28 | 闪现：每 4 秒在你前进方向前方亮红圈，0.75 秒后闪现过去 |
| 8:00 | P0 线上事故 | 1600 | 26 | 弹幕：每 3.2 秒蓄力 0.6 秒，向四周发 12 发告警弹（伤害 14，楼能挡），每轮错开半格 |
| 9:00 | 老板画饼 + AI 大模型 | 1900 | 24 | 扔饼：每 3 秒朝你要去的位置扔 3 个饼，落点先出阴影，1.1 秒后落地（伤害 18）。同时出场的 AI 大模型带分身，血量是 5:00 那只的 85% |

被「站会」定住时，boss 只定一半时间（倒计时也停）。「召唤」只有屎山代码有。每种招式每局第一次出现时，底部红字提示怎么躲。

设计原则：机制换玩法，不涨总难度。每个新机制都配一个补偿：主库宕机的冲击也震开小怪，Deadline 按时打掉有保底 A 轮，投资人降血量并在死后洒星星，终局的 AI 降血量。数值都在 `scripts/enemy.gd` 顶部和 `scripts/spawner.gd` 的 `ENEMY_TYPES`。

### 2.7 刷怪节奏

- **刷怪速率**：每秒 `(0.8 + 分钟数 × 0.55)` 只，开局按 60% 刷、3:00 回到 100%；10 分钟时约每秒 6.3 只。刷在屏幕外 40 像素，40% 的概率偏向玩家走的方向。
- **血量倍率**：普通怪和 boss 的生命都乘 `1 + 分钟数 × 0.2`（10 分钟时 3 倍）。
- **同屏上限**：电脑 260、手机 200（boss 召唤和分裂不受上限限制）。
- **拉回**：离玩家超过 560 像素的怪会被挪回玩家前方，压力不会因为跑远而消失。
- **小怪配比**（按时间段）：

| 时间段 | 小怪配比（权重） |
|---|---|
| 0:00–0:30 | 只有 Bug |
| 0:30–1:00 | 消息红点 3、Bug 2 |
| 1:00–2:30 | 红点 2、Bug 3、邮件 2 |
| 2:30–4:00 | Bug 1、邮件 3、会议 2、幽灵 1 |
| 4:00–5:30 | 邮件 2、会议 2、幽灵 2、技术债 2 |
| 5:30–7:30 | 会议 2、幽灵 2、技术债 3、服务器 1 |
| 7:30–10:00 | 邮件 2、幽灵 2、技术债 3、服务器 2 |

- **包围圈**：1:30 消息轰炸（16 个红点围一圈）、3:30 Bug 大爆发（30 个）、6:30 404 幽灵合围（30 个）、8:30 消息轰炸 ×2（48 个）。
- **Boss 上限**：场上已有 3 个 boss 时，下一个 boss 等有 boss 倒下才出场；包围圈照常。原因是早期数据里打不过的人死时场上压着 4–5 个 boss。
- **提示**：boss 来之前 20 秒，计时器下方出现「下一个 boss 0:12」倒计时；屏幕外的 boss 在屏幕边缘用带头像的红色箭头指出方向。

### 2.8 难度

只有一个难度。`.5` 曾加过「实习生 / 正式员工 / 996」三档（开始画面选，暂停页和结算页可换并重开），`.6` 去掉了，所有人都按原来的「正式员工」数值玩。

### 2.9 结算

- 整页：结局（GAME OVER / IPO DAY）、第几局、存活时间 / 等级 / 击杀、**凶手**（头像、名字、死因：冲锋撞死 / 告警弹命中 / 被饼砸中 / 被 boss 撞倒 / 被围殴；通关时显示「差点送走我的」）、伤害排行（按占比，最多 6 行）、一条建议（只在输了时）。
- 建议按死法给，第一句加粗：只带了 1–2 把武器 → 先拿武器卡凑够 3–4 把；被 2 个以上 boss 围住 → 边走边打；倒在 boss 招式下 → 看地上的预警躲；2 分钟内死 → 走到星星旁边才能捡到经验；其他 → 多拿撸铁或降噪耳机。
- 按钮：「生成战绩图」、「再来一局」。
- **战绩图**：720×1280 竖图（`ui/share_card.gd`），黄色外框里一张白卡：结局、超大的存活时间（输了写「离上市还差 mm:ss」）、职级胶囊（1–9 级 L3、10 级 L4，每 10 级升一档，50 级以上 L8）、击杀、最强武器和占比、凶手、一句吐槽（按凶手或存活时间挑）、二维码（链接带 `?from=share`）。网页上盖一层显示：手机长按保存或转发；浏览器支持时有系统分享；不在微信里时可以下载。**分享不给任何奖励**（微信规则禁止诱导分享）。

## 3. 地图：湾区


- **结构**：无限延伸的街区网格（每个街区 560×400 像素），按旧金山湾区的真实轮廓排布。玩家从帕洛阿尔托 / 山景城一带出生。往北半岛变窄，经过 SFO 机场跑道到旧金山，北岸外是金门海峡的水；西边是 Sand Hill Road 的金色山丘和红杉，再往西是太平洋和海滩；东边是盐田和海湾，越往南海湾越宽，到圣何塞收尾；圣何塞往南、往东无限延伸。
- **分区**：硅谷（默认的科技园区）、旧金山（维多利亚排屋）、圣何塞（西班牙红瓦房、商店）、山区（稀疏小屋、红杉）、海滩、海湾。小地图下面显示当前所在区。
- **道路**：路口立着真实街名的路牌（El Camino Real、University Ave、Sand Hill Rd、旧金山的 Van Ness Ave、Market St……）。US-101 沿海湾一侧、I-280 沿山一侧，画成更宽的高速（双黄线、路面路线盾牌、隔一个街区一块绿色路牌），上面跑着无人车；Caltrain 铁轨沿 Alma St 贯穿南北，火车隔一阵开过。**车和火车只是风景，不撞人也不撞怪。**
- **地标**：斯坦福钟楼、Caltrain 帕洛阿尔托站、Pear 园区（苹果梗）、Goggle 园区和恐龙骨架、Beta 园区和大拇指牌、LinkedOut、Envy、NUTFLIX 园区、Out-N-In 汉堡店、Levy's 球场、SFO 跑道和飞机、泛美金字塔、Sailsforce 塔、金门大桥。目前**都只是风景**。
- **恶搞招牌**：Pear、Goggle、Beta、Envy、NUTFLIX、LinkedOut、Sailsforce、Sand Hill Capital……名字和图标全是自己画的谐音梗，不用任何真实 logo。
- **碰撞**：楼只有底座（沿正面一条 24 像素深）挡路，可以绕到楼后面，楼会变半透明；草地上的树干和海水也挡路。一排楼之间至少留 36 像素的缝，最大的 boss 也挤得过去。404 幽灵穿墙。武器投射物从楼上飞过。三面是海，容易被逼到海边。
- **寻路**：怪被楼挡住时沿寻路图绕过去，不会贴墙卡住。
- **小地图**：右上角，固定显示整个湾区（海岸线、两条高速和铁路、各区颜色），标出玩家、当前屏幕范围、boss（红点）；走出湾区范围时自动缩小把玩家也装进去。
- **生成方式**：每个街区的楼、树、道具都由街区坐标的哈希决定，所以永远不重复、走回去还是一样的，也不用存。

## 4. 界面

按设计画布「硅谷幸存者 · 界面设计」（Sokosoko 风格）实现，控件在 `scripts/ui/ui_kit.gd`，画面在 `scripts/ui/hud.gd`。竖屏按 360 宽的逻辑尺寸、和设计稿一比一；横屏（640×360 起）用同一套风格排成左右两栏。任何画面在最极端的内容下（英文、5 张卡、开出 5 样）放不下时整体缩小到放得下。

### 4.1 视觉规则

- 米白底（#faf7f0）、白卡片、墨色（#2f3542）文字和描边；**主按钮**黄底（#f7c948）、3px 墨色描边加底部 4px 硬阴影，每屏一个；次按钮白底灰边；按钮和标签都是胶囊形。
- 弹出且暂停游戏的对话框（升级、融资开奖、暂停）用深色遮罩盖住战场，卡片是白底、3px 墨色描边、20 圆角；结算和设置是整页。
- 标题上方有一行英文小字（LEVEL UP、FUNDING ROUND、GAME OVER、IPO DAY），中英文都显示英文。
- 颜色约定：武器浅蓝（#e5f0fb）、被动浅绿（#e3f4ea）、危险和 boss 红（#b23344）配浅粉（#fde6e8）、主角血条红（#d94b5c）、数字和说明的蓝字（#2f6fb0）。
- 选项是分段胶囊，选中的那段墨色底白字；开关是黄色轨道加圆钮。

### 4.2 局内 HUD

- 左上：武器格、被动格各 6 个，图标加墨色等级角标。
- 顶部正中，从上往下：经验条（短胶囊，里面写 Lv）、计时器（大号白描边数字）、下一个 boss 倒计时（boss 来之前 20 秒出现，红框）、boss 条（场上待得最久的 boss：名字、血条、还有几个「+N」）。
- 右上：击杀数、陀螺仪校准（开了陀螺仪才有）、暂停；下面小地图和所在区。
- 主角脚下血条只写当前血量；低血量时屏幕边缘泛红。
- 屏幕外的 boss 在屏幕边缘用粉底红圈的头像加箭头指方向。
- 底部提示：前 3 局开局 2 秒没动时提示怎么移动；每局每种 boss 招式第一次出手时，红色提示怎么躲（冲锋、召唤、闪现、弹幕、扔饼各一句）。
- 每台设备第一次掉星星时，顶部提示一句，并在那颗星星上画跳动的箭头。
- 摇杆只在按住时出现，直径 96。

### 4.3 各个画面

- **开始画面**：两个装饰圆、英文小字、带荧光笔条的大标题、两行介绍、一排站在线上的角色（会跳）、「开始搬砖」大按钮、「设置」、底部操作提示、右下角版本号。
- **升级**：遮罩上的「LEVEL UP / 升级！Lv N / 选一张带走」，竖屏卡片竖排、横屏并排。卡片：图标井（新武器浅蓝、已有武器的升级灰、被动浅绿、回血粉）、名字、「新武器 / 被动」标签或等级点（下一级是黄点）、文案、蓝字数字。新手保底的「推荐」卡用粗边加硬阴影，角上挂「推荐」。底部一句说明。
- **融资开奖**：钱袋压在卡片上沿；竖向转轮（上下两格是没选中的轮次）转 1.6 秒停下；三档概率说明，开中的那档高亮；「A 轮到账！白给 3 样升级」；开出的升级逐行列出（Lv 2 → 3；同一样升了两级合成一行，Lv 3 → 5）；「收下」。转的时候点按钮直接出结果。
- **暂停**：白卡：「暂停」和当前时间；武器、被动两列标签（名字 + Lv）；属性小格（生命只写当前值、伤害 ×、冷却 ×、移速、拾取、护甲 · 回血）；「继续」大按钮，下面「重新开始」「设置」。
- **设置**：整页，带返回按钮：语言（中文 / English）、屏幕方向（手机：跟随手机 / 横屏）、陀螺仪、音效、音乐开关，陀螺仪说明，「完成」。
- **结算、战绩图**：见 2.9。

## 5. 设计原则与约束

- 一局 10 分钟、点开就玩；手机单手竖屏优先，任何新操作都要能单手完成。
- boss 的每个招式出手前都有预警，保证能躲，第一次出现时告诉玩家怎么躲。
- 新手的帮助只给提示（保底武器卡、推荐标签、移动和星星提示、结算建议），**不偷偷降低难度**。
- 题材恶搞硅谷职场：不用真实公司 logo 和字标，不用真实人名和照片，谐音梗可以。
- 不做广告、内购、诱导分享、联网对战。
- 每次上线都把 `VERSION` 升一号，对局数据按版本区分；改动最好能用对局数据验证。
